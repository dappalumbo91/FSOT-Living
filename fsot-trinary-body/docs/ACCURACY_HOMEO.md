# Pack accuracy homeostasis

Self-model was the first organ with **low-acc → more stimuli**. This extends that
to **every** scored modality.

## Healthy bands

| Band | Threshold | Organs |
|------|-----------|--------|
| core | ≥62% | cognitive, language, code, vision, knowledge |
| social | ≥55% | collective |
| media | ≥52% | audio, video |
| script | ≥48% | js, composition |
| meta | ≥55% | self_model, gen_acc (language generalize) |
| l2 | ≥25% | code_l2 (sparse exam surface) |

## What happens when weak

1. **Teach inject** — organ-specific ACCURACY_HOME prior  
2. **Mild skill/acc nudge** — opens the floor; **exams still earn real gains**  
3. **Exam bias** — heavy rotation prefers weakest organ ~80% of slots  
4. **Audit file** — `ACCURACY_AUDIT.json` every ~35 ticks

## Honest note

Homeostasis is **feed**, not free grades. A 0% code_l2 organ gets a soft open and
more multi-file pressure; it does not jump to 90% without exam passes.
