# Mind · Body · Soul — working map (not dogma)

A thought that landed while building: **mind / body / soul**.  
We treat it as an **engineering topology**, not a metaphysical claim.

| Everyday word | In this stack | Substrate |
|---------------|---------------|-----------|
| **Body** | Trinary soma, sensors, organs, sleep/dream, QEMU or host chassis | **Hardware** (or hardware-faithful simulation) |
| **Soul** | Continuity software: LIVE_STATUS, germline LATEST, identity sessions, LTM, skills | **Software state that persists** |
| **Mind** | Habitat process: selection, exams, language, felt report, choice under pressure | **Living loop** (what is happening *now*) |

The soul without a body is a save file.  
The body without a soul is a zygote every boot.  
The mind without either is a chat demo.

Continuity work (STM resume + germline + felt interoception) is how those three **stay one organism**.
