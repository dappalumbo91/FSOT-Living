# Principals — Human vs Mind (revised)

## No-brainers fixed

| Capability | Mind | Human | Why |
|------------|------|-------|-----|
| **SLEEP / SAVE** | ✓ | ✓ | Intelligence must survive boots & generations. Auto-consolidation is cortex-native (biological sleep). |
| **WRITE /home/identity** (full replace) | ✗ | ✓ | Full rewrite = personality wipe. Dangerous. Human-only emergency. |
| **APPEND /home/identity** | ✓ | ✓ | Episodic `session:` traces only — does not clobber `core:`. |
| **DEFRAG /home/identity** | ✓ | ✓ | Reorganize/dedupe; **preserves `core:`** lines. |

## Identity layout (not a free rewrite)

```
core: companion self · FSOT biological identity
session: gen=3 champion=elite-g3-0 breed=12.4 scale=max
session: gen=4 champion=elite-g4-1 …
```

- **`core:`** — stable autobiographical self (Human may rewrite; Mind defrags only)  
- **`session:`** — what happened across gens (Mind appends, then defrags)

**DEFRAG** = waking, explicit compact (core-safe).  
**DREAM** (inside SLEEP only) = FSOT connective self-organization — see [DREAM_STATE.md](DREAM_STATE.md).  
**WRITE** on identity = nuclear option, Human only.
