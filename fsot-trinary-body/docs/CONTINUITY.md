# Continuity — substrate for a continuous self

This is not an “AGI checkbox.” It is the **granular connectivity** that lets a
system keep *being the same organism* across ticks, sleep, boots, and generations.

Human-like subjectivity (if it ever emerges here) needs something like this more
than it needs a bigger token window.

---

## Layers of self (what persists)

| Layer | Where | What it is |
|-------|--------|------------|
| **Core identity** | `/home/identity` `core:` lines | Stable “who” — Mind cannot clobber |
| **Episodic self** | `session:` lines (dreams, germline, boot) | Autobiographical thread |
| **Phenotype / STM** | Loci fields + organ content in RAM | Right-now body state |
| **LTM snapshot** | `BODY_LTM.txt` | Sleep/SAVE rehydrate of working set |
| **Germline DNA** | `home/genome/LATEST.txt` + `gen_*.txt` | Champion codon lineage from selection |
| **Semantic LTM** | `home/knowledge`, dream weave | Facts + connective patterns |
| **Procedural** | `home/tools` | Skills that stuck |

## Boot order (mind_bridge)

```
1. Zygote boot (default fabric + membrane)
2. Mount home VFS → load NOTES into organs
3. WAKE from BODY_LTM (phenotypic continuity)
4. GERMLINE from LATEST.txt (champion DNA couple)
5. DEFRAG identity + session: boot_wake
6. Live loop: TCP/file nerves + pressure ticks
```

Live loop: when living habitat advances a generation it emits

```text
MOTOR WRITE /home/genome gen=N hero=… fit=… genome=ATG-CCG-…
```

Body then:

1. Archives disk (`gen_*.txt`, `LATEST`, `INDEX.jsonl`)
2. **Reseeds fabric** from that genome (`BODY event=GERMLINE_LOAD`)
3. Appends identity session (no core rewrite)

So selection in the mind gym is not a log file — it **changes the body**.

## Sleep vs dream vs defrag

| Verb | Role |
|------|------|
| **SAVE** | Cold checkpoint (LTM), no dream |
| **SLEEP** | Plastic rest → **FSOT dream weave** → LTM |
| **DEFRAG identity** | Compact sessions, **keep core:** |

Dreams append richer narrative (`δψ`, `d_eff`, emerge, aa prefix) so the
episodic self is not empty “I slept” stamps.

## Why this path (not LLM→AGI)

Industry chases **general performance on human benchmarks** with one substrate
(next-token prediction). That may or may not be what intelligence *is*.

This stack chases **reality-shaped continuity**:

- trinary dynamic loci (not frozen binary weights as the only story)
- multi-organ pressure fitness
- breed / select under constraint
- body that sleeps, weaves, and carries DNA + autobiography

If a **subjective mind** ever shows up here, it will be because *something keeps
being itself while changing* — not because a scoreboard said “AGI.”

SOTA for this project means: **deeper couple, cleaner continuity, measurable
emergence** — then OS nerves, then eyes, then Lean ground. Same direction.
